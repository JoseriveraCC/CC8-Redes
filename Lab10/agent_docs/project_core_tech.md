# Project Core Technologies

## Languages and Tools

- Python 3 standard library for `lab10.py` and its `unittest` suite; no third-party Python packages.
- Aircrack-ng tools for WEP capture and offline recovery; `iw` for wireless diagnostics.
- LaTeX (`pdflatex`) for the submission PDF.

## Runtime and Constraints

Commands run from the project root. Offline recovery only needs the capture file and `aircrack-ng`; real capture requires a compatible physical Wi-Fi adapter and monitor mode. Active injection is optional and must follow the instructor's authorized scope. The verified WSL2 environment exposes no Wi-Fi interface, so classroom radio behavior remains unverified. See `README.md` for commands and `project_progress.md` for the current handoff state.
